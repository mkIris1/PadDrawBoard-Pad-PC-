## Google Android SDK Platform-Tools 36.0.2

The Windows package contains the complete official `platform-tools` directory
under `tools/adb/36.0.2/`. In particular, Google's `NOTICE.txt` and
`source.properties` are copied unchanged; no Platform Tools binaries are
stored in this repository. The acquisition lock is in
`packaging/platform-tools.lock.json` and is verified before extraction.

- Publisher: Google Android SDK Platform-Tools
- Fixed source URL: `https://dl.google.com/android/repository/platform-tools_r36.0.2-win.zip`
- SHA-256: `B024D4F319D6AD3004DE1BA7B96A5C7C5F3512E8B14126308D598B4AB93DCEAD`
- Release notes: <https://developer.android.com/tools/releases/platform-tools>

The public Google endpoint calls this file `-win.zip`; the local cache name
`platform-tools_r36.0.2-windows.zip` is only a descriptive filename. The
build never follows the mutable `platform-tools-latest-windows.zip` link.

## Gradle Wrapper

The checked-in Android Gradle wrapper is generated by Gradle and is licensed
under Apache License 2.0. Its wrapper distribution is pinned by
`android/gradle/wrapper/gradle-wrapper.properties` and its wrapper JAR carries
the corresponding license metadata. The wrapper is used only to build and
test the Android client.

## Android/Kotlin build dependencies

The Android build resolves the Android Gradle Plugin, Kotlin Gradle plugin,
AndroidX test runner, and JUnit from their declared repositories. Their own
licenses and notices remain with the resolved distributions; PadDrawBoard does
not redistribute those dependency caches in a release archive.

## Signing and trust

Release artifacts are not code-signed by this repository. The Windows ZIP and
NSIS installer are unsigned, the debug APK uses the local Gradle debug key,
and the release APK is intentionally `app-release-unsigned.apk`. A public
trusted release must be signed by the distributor using a protected
Authenticode certificate and Android release keystore.
